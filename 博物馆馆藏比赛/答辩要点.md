# 答辩要点（评委问答预案）

> 共 14 问，按评审四维度分组；★ 为高危必答。
> 应答纪律：所有数字与口径以《设计说明》《演示讲解稿》为准；**答不上来的问题，宁可说「这一点我们还没验证」，绝不作即兴推测**。

## 一、藏品契合度（35%）

### ★Q1 《Caractères chinois》是戴遂良写的，和腊味爱、和馆藏到底是什么关系？

1. 直接讲清归属，不回避：该书作者是法国耶稣会汉学家戴遂良（Léon Wieger，1856—1933），1905 年河间府天主教传教团印刷所出版，是一部基于《说文解字》的字源字典。
2. 腊味爱是**使用者**：这是他案头的「文字考古」工具书；工具是前人的，**把这部字典转用于中医概念、经络与腧穴命名的拆解，并由此形成方法，是腊味爱的贡献**。
3. 我们全流程的表述纪律：凡出现该书，主语一律是「腊味爱案头的字源字典（戴遂良著）」，从不写成腊味爱著作。
4. 一句话收束：「宣纸上是腊味爱的笔，字典上是戴遂良的笔——两者并不冲突。」

### ★Q2 字形数据来自甲骨文AI协同平台，不是馆藏，凭什么说「取材自馆藏」？

1. 先承认边界，再立三层取材：**方法取材**（腊味爱的「以字释义」）、**实物取材**（馆藏照片「腊味爱在法国家中用毛笔书写信件」——毛笔书写汉字这一行为母题）、**精神取材**（把中医译介给非中文读者的跨文化姿态与治学克制）。
2. 主动说清字形数据出处：甲骨文AI协同平台「甲骨文合并字表」已释字（权威字表 1530 条）——**我们不声称**这是馆藏文物的摹写或三维复原。
3. 定性：这是一次**方法型活化**，不是**器物型复原**——馆藏给的是钥匙，作品造的是那把钥匙能开的门。
4. 可补强项（如时间允许）：在页面或视频片尾加一行「取材自云南中医药大学中医西学博物馆腊味爱文献」，把归属字样留在作品里。

### ★Q3 那张照片你实际用在哪？只是当引子吗？

1. 三处用途：设计说明的题眼、演示视频首帧、以及**媒介转译的支点**——毛笔是手的延伸，手势也是手的延伸。
2. 明确不做什么：**不**声称照片被用于三维建模、图像素材或任何直接复制。
3. 照片的价值在行为不在像素：它记录着一位法国人用毛笔书写汉字——这个行为本身就是「跨文化表达」的证据。

### Q4 腊味爱是法国人，用他的方法讲中医，会不会讲成「外国人的中医」、反而失真？

1. 方法是**入口**不是**结论**：「以字释义」讲的汉字与中医概念的构造关系（氣 = 气 + 米），不是西方视角的再叙述。
2. 有学理支撑：贾成祥《中医藏象学说的文化根源》指出「意象思维是藏象学说构建的文化根源」，腊味爱的做法与之同构——这不是外来附会，而是触到了中医自身的语言底色。
3. 有他证：其弟子麦斯特拉雷认为「以字释义是开启通向中医权威和传统的大门」——在法国中医圈内部，这是被承认的方法。
4. 反向价值：正因方法论出自一位法国人，它天然是「跨文化表达准确」的样本——中医走出去，靠的就是这种能被非中文读者握住的形式。

## 二、文化传承性（25%）

### ★Q5 你们字库里没有肝、脾、肺、肾、医，医学专业性在哪里？

1. 正面把它变成**立场**：肝、脾、肺、肾、医等字殷墟甲骨文未收录（后世字），字库中**不以拟古字冒充**——这是学术克制，不是知识缺口。
2. 用**在场**的字承担医学内涵：心（脏腑唯一见甲骨文，「君主之官，开窍于舌」）、疾（一人卧床、身中一矢）、龋（甲骨文记载的人类最早疾病之一）、酉（医酒同源）、石（砭石刺病）、耳/目/舌/鼻（四窍）；精选 67 字覆盖脏腑五行、四窍、疾病、医之源、天人、物象六类。
3. 与腊味爱的治学态度对举：他不因一时无法解读就否定中医的价值；我们也不因缺字而造字。
4. 边界说明：作品定位是**公众入口**，不是全科教材。

### Q6 「以字释义」是不是文字游戏、过度诠释？

1. 方法有学理根基（贾成祥；「圣人立象以尽意」），有传承链条（腊味爱 → 法国「甲骨文中医流派」→ 弟子评述），不是团队自创的诠释框架。
2. 释义边界严格：只对字表可考、有码位的字做释义；67 字精选全部人工编排、逐条可追溯。
3. 例证选的是字形本身可读的构造：氣 = 气 + 米；心象心脏之形、开窍于舌；疾以战伤释病；龋象齿间啮虫——不依赖联想。
4. 反过来说：如果只讲抽象医理，非中文观众一个字都拿不走；「以字释义」恰恰是把「不可触摸」变成「可触摸」的那一步。

### Q7 只讲甲骨文，中医的临床与理论体系在哪里？

1. 定位澄清：本作品不做中医学理体系的全景呈现，做的是一个**可被公众握住的入口**。
2. 「象」是中医自身的语言：意象思维是藏象学说的文化根源——我们呈现的是中医的语言地基。
3. 可延展性：字库是数据层（1063 字）、精选是编排层（67 字），后续向经络、腧穴命名扩展只需在数据层加字、重建一次即可。

## 三、数智创新性（20%）

### ★Q8 粒子是位图采样、不是笔画矢量，谈何「精确」？

1. 直接说明技术路径，不美化：字形取自**真实甲骨文字体**（AYJGW 甲骨文字体，PUA 码位），程序把字形栅格化后**按墨迹逐像素采样**成粒子目标点——笔画由字体轮廓决定、不由人手描绘，**不存在「用现代汉字改画」**。
2. 澄清一处常见误读：**不是**按笔顺逐笔书写，而是一次性聚形；粒子亮度 = 墨迹浓度（笔心亮、边缘暗），这是「气」的视觉语法。
3. 精度责任分层：字形准确性由字体与字表保证（字体本身是矢量轮廓），粒子层负责表现；成字瞬间强制正视，保证观众看到的字形永远是正的、不因视角变形而误读。

### Q9 和殷契文渊、甲骨文AI协同平台这些成熟项目比，差异在哪？

1. 定位不同：那些平台是**面向研究者的字表、检索与考释工具**；本作品是**面向公众的展馆交互装置与巡播系统**——我们在「博物馆场景的转译层」，不重复造字表。
2. 数据上我们是下游：字形与已释字数据正来自甲骨文AI协同平台「甲骨文合并字表」，可追溯、可核验——是可审计的来源，不是自造数据。
3. 交互上我们是正交的：把手势的聚散语义与「气」绑定（捏合 = 气聚成字、张开 = 字化气散），是现有甲骨文项目没有做的事。
4. 部署上更轻：完全离线、单文件自包含、无 CDN——能直接塞进博物馆大屏的形态。

### Q10 技术上是 Three.js + MediaPipe 的常规组合，创新点在哪？不就调库吗？

1. 不宣称算法首创，创新在**语义绑定与场景工程**：手势动作与中医「气」的概念一一同构，这是设计层的创造。
2. 工程细节可举证：7000 粒子点云；聚形 1:1 连续跟手；成字一刻强制正视 + 粒子闪光 + 钟声 + 标题释义多通道反馈；挥掌生风、双手两枚气引点；无摄像头自动回退鼠标。
3. 场景创新：**45 秒无输入进入展馆巡播**，18.4 秒/字，67 字一轮约 20 分钟，且只在中医主题字中巡播——「屏保语义」的无人值守方案，有人触碰立即接管。
4. 交付形态创新：完全离线、单文件自包含、字体子集 base64 内嵌、无 CDN——弱网与无网展馆可直接部署。

### ★Q11 字体和数据有授权吗？参展、再分发合规吗？

1. 坦诚现状：第三方组件已逐项登记在仓库 THIRD-PARTY-NOTICE 中；Three.js（MIT）与 MediaPipe Hands（Apache-2.0）已确认可再分发。
2. 甲骨文字体（AYJGW，© AYSY.JKX, 2003）与字表数据的再分发授权**正在与版权方确认**——这是主动披露的风险项，而非隐瞒。
3. 已备退路：若授权未获，可将字体移出内嵌包，改为「提供下载指引 + 本地子集化脚本」的形态，作品功能不受影响（字体仅用于构建期）。
4. 表述纪律：不声称 67 字释义全部为团队原创——部分条目的 tag 与释义与平台文案一致，来源与继承关系已写在声明文件中。

## 四、传播适配性（20%）

### Q12 展馆里真能用吗？掉网、没摄像头、机器旧怎么办？

1. 无摄像头：自动回退鼠标模式（按住 = 捏合聚形，松开 = 气散，拖动 = 旋转），大屏可配触摸或遥控。
2. 无网：完全离线、单文件自包含、无任何 CDN 依赖；页面与字体、手势模型全部本地化。
3. 体量：主页面约 1.6MB（服务器压缩后约 850KB）；手势运行时首次加载后走长缓存。
4. 无人值守：45 秒无输入进入展馆巡播，有人触碰立即接管——不设操作员也能一直在「演」。

### Q13 观众玩两下就走了，怎么证明它有效？

1. 不编造数据：目前没有埋点或问卷数据——**不声称**停留时长、参观人次等指标。
2. 给可达性论证（可证明的设计事实）：不懂汉字的人看聚散之美，会汉字的人认字形，研究者可读释义与来源——三层入口，任一层都能停住脚。
3. 给可验证的下一步：可加参观停留时长、手势触发次数、待机被接管次数等指标采集，用于迭代——把问题转成路线图。
4. 现场补一句：展馆巡播被触碰的次数，本身就是最直接的「有人愿意互动」信号。

### Q14 为什么用「手势」而不是点击？交互是不是为了炫技？

1. 「气」本身是聚散的动态概念：捏合 = 气聚成字，张开 = 字化气散——手势不是装饰，是把概念还原成身体动作。
2. 与毛笔的隐喻同源：腊味爱用毛笔（手的延伸）书写汉字，观众用手势（同为手的延伸）把字聚拢——跨媒介的同一动作。
3. 兜底不牺牲可达性：保留鼠标模式，手势是加分项而非门槛。
4. 页面不显示相机画面、只显示手部骨架——隐私友好，展馆场景可直接开启摄像头。
