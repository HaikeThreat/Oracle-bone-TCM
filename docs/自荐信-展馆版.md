**关于《智解甲骨·中医密码》数字展项的合作自荐**

尊敬的【XX 博物馆 / 展览馆】展陈部：

您好。

我叫【姓名】，独立完成了数字交互作品《智解甲骨·中医密码》。它是一个可在**普通电脑浏览器里离线运行的展项**：摄像头前伸出手，拇指与食指轻轻一捏，七千颗光点便如星云流转，聚成一个三千年前的甲骨文字形；手掌张开，字又散作气，回归星空。若无人操作，它会自己继续演下去——每约十八秒，星云重新聚成下一个字。

我冒昧来函，是因为这个作品的核心形态，其实**不是一件需要观众动手的互动装置，而是一段可以自己演下去的"字"的影像**。这一点，我认为正合展馆的日常需要。

## 一、它为什么适合展馆

**它无需值守。** 观众不来，它自己巡字；观众一伸手，它立刻交还控制权；观众走开四十五秒，它又接着自己演。一轮六十七个字，约二十分钟循环一遍——挑的都是与中医、身体、疾病、草木相关的字（心、目、舌、耳、孕、疾、龋、药、酒、风……），不是随机抽取的通用字。

**它不挑场地。** 整站是一个自包含的网页，约 25 MB（16 个文件），**完全离线、不依赖任何外部网络或 CDN**。一台普通电脑接一块大屏，开机全屏即可；不需要显卡阵列，也不需要联网授权。展馆最怕的"开展当天网络不通 / 供应商服务器到期"，在这里不存在。

**它有内容，不只是视觉。** 每一个字都配了标题与释读：为什么「疾」是一个人卧在床上、身上中了一箭；为什么「龋」是甲骨文里记载的人类最早疾病；为什么「心」是唯一在甲骨文中可见脏腑的汉字。观众看到的不只是粒子特效，而是三千年前中国人对身体的认识。

**它对观众友好。** 观众无需佩戴任何设备，隔空手势即可；若摄像头不便，会自动回退为鼠标操作，功能不减。摄像头画面**不出现在屏幕上**（仅显示手部骨架），不涉及观众肖像采集与留存。

## 二、技术上的一句话交代

单个 HTML 文件（1.55 MB），Three.js 七千粒子点云 + MediaPipe 手势追踪，字体子集与字库全部内嵌，三千三百行代码，从数据到渲染没有第三方服务依赖。可部署在本地电脑、展馆内网服务器或一体机上，亦可按贵馆的屏幕尺寸与横向纵向重新适配。

## 三、我希望得到的

坦率说，我不确定它最适合放在贵馆的哪个位置，因此不敢预设合作形式。可能的形态有三种，供您判断：

1. **常设或临展中的一个展项**：一台电脑、一块大屏、一个摄像头，靠墙一角即可；
2. **展厅的开场或过场影像**：无人操作时的自巡字模式本身就是一段二十分钟的循环影像，无需观众参与；
3. **教育活动 / 研学课程的教具**：可配合"甲骨文里的身体观"这类主题讲解，观众分组上手。

若贵馆有意，我可以**免费提供完整作品供试用**，并按贵馆的场地条件做适配调整（尺寸、巡字内容、单字释读文案、是否需要简体或繁体界面）。是否需要签订授权、是否需要适配到指定屏幕，都可以按贵馆的规范来。

## 四、可以立刻验证

作品目前可在我方设备或局域网内直接演示（在线地址的手续正在办理中）。我也可以先录制一段两分钟的实拍视频供您过目，或按您方便的时间上门演示一次，二十分钟即可看完一个完整循环。

若此方向与贵馆的展陈规划不合，也恳请不必费心回复；若有一丝可能，盼能给我一次当面演示的机会。
